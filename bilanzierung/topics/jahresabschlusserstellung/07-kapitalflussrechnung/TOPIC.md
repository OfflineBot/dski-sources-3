# Kapitalflussrechnung

Die Kapitalflussrechnung (Cashflow-Statement) ist ein wesentlicher Bestandteil des Jahresabschlusses und ergänzt die Bilanz und Gewinn- und Verlustrechnung. Sie zeigt die Zahlungsströme eines Unternehmens während eines bestimmten Zeitraums.

## Ein- und Auszahlungen (Cash Flows)

**Definition:** Als „Einzahlung“ (positiver Cash Flow) bzw. „Auszahlung“ (negativer Cash Flow) bezeichnet man einen Zu- und Abfluss von liquiden Mitteln aus dem Unternehmen. Darin eingeschlossen sind physische Geldmittel sowie Bankguthaben.

## Arten von Cash Flows

| Operativer Cash Flow | Investitions-Cash Flow | Finanzierungs-Cash Flow |
|---|---|---|
| Cashflow aus laufender Geschäftstätigkeit | Cashflow aus Investitionstätigkeit | Cashflow aus Finanzierungstätigkeit |
| Bildet operative Zahlungsflüsse ab. | Bildet die Zahlungsflüsse aus Investitionen und Desinvestitionen in langfristiges Anlagevermögen ab | Bildet die Zahlungsflüsse aus Finanzierungen ab, die im Eigenkapital oder Fremdkapital gebucht werden. |
| Z.B. Auszahlungen an Lieferanten, Einzahlungen aus Verkäufen | Z.B. Auszahlung für den Erwerb einer Maschine. | Z.B. Aufnahme von Darlehen, Rückzahlung von Darlehen, Aufnahme von Eigenkapital |

## Zweck der Kapitalflussrechnung

1. **Analyse der Liquidität:** Wie viel Geld erwirtschaftet das Unternehmen tatsächlich und hat es zur Verfügung? Kann es seinen Zahlungsverpflichtungen (Löhne, Lieferantenrechnungen, Kreditzahlungen) nachkommen?
2. **Beurteilung der Zahlungsströme aus operativer Tätigkeit:** Der operative Cashflow (Geldflüsse aus der laufenden Geschäftstätigkeit) zeigt, ob das Kerngeschäft genügend Einzahlungen generiert, um die laufenden Kosten ohne externe Finanzierung zu decken.
3. **Bewertung der Investitionsfähigkeit:** Wie viel Kapital wurde für Investitionen in langfristige Vermögenswerte wie Maschinen, Immobilien oder Technologien verwendet (Cash Flow aus Investitionstätigkeit)? Wichtig, um zu beurteilen, ob das Unternehmen seine Marktposition stärkt und für die Zukunft wächst.
4. **Finanzierungsstruktur verstehen:** gibt Einblick in die Finanzierungsaktivitäten, z. B. wie viel Kapital durch Kredite, Anleihen oder Eigenkapitalbeschaffung aufgenommen oder zurückgezahlt wurde (Cash Flow aus Finanzierungstätigkeit). Entscheidend für die Beurteilung der Verschuldung und der Kapitalstruktur.

## Beispielhafte Kapitalflussrechnung

| Position | Betrag (€) |
|---|---|
| Cashflow aus operativer Tätigkeit | |
| Gewinn des Geschäftsjahres | 100.000 |
| + Abschreibungen auf Sachanlagen | 20.000 |
| + Abnahme der Forderungen aus Lieferungen und Leistungen | 10.000 |
| - Zunahme der Vorräte | (5.000) |
| + Zunahme der Verbindlichkeiten | 15.000 |
| = Operativer Cashflow | 140.000 |
| Cashflow aus Investitionstätigkeit | |
| - Erwerb von Sachanlagen | (50.000) |
| + Verkauf von Finanzanlagen | 10.000 |
| - Erwerb von immateriellen Vermögenswerten | (5.000) |
| = Cashflow aus Investitionstätigkeit | (45.000) |
| Cashflow aus Finanzierungstätigkeit | |
| + Aufnahme von Darlehen | 30.000 |
| - Tilgung von Darlehen | (10.000) |
| - Ausschüttung von Dividenden | (20.000) |
| = Cashflow aus Finanzierungstätigkeit | 0 |
| Nettoveränderung der liquiden Mittel | 95.000 |
| Liquide Mittel am Anfang des Geschäftsjahres | 50.000 |
| Liquide Mittel am Ende des Geschäftsjahres | 145.000 |

Erklärung der einzelnen Positionen:

- **Cashflow aus operativer Tätigkeit:** Zahlungsfluss aus der Hauptgeschäftstätigkeit. Berechnung: Jahresgewinn, angepasst um nicht zahlungswirksame Posten wie Abschreibungen sowie Veränderungen im Umlaufvermögen. Im Beispiel 140.000 €.
- **Cashflow aus Investitionstätigkeit:** Investitionen und Desinvestitionen in das Anlagevermögen. Im Beispiel: Sachanlagen erworben (Ausgabe von 50.000 €), Finanzanlagen verkauft (Einnahme von 10.000 €); Netto-Cashflow -45.000 €.
- **Cashflow aus Finanzierungstätigkeit:** Ein- und Auszahlungen im Zusammenhang mit der Finanzierung des Unternehmens. Im Beispiel: neue Darlehen aufgenommen (30.000 €), bestehende Darlehen zurückgezahlt (10.000 €), Dividenden ausgeschüttet (20.000 €); der Finanzierungscashflow ist neutral.
- **Gesamtergebnis:** Nettoveränderung der liquiden Mittel 95.000 €; am Ende des Geschäftsjahres 145.000 € liquide Mittel.
