# Gewinnvergleichsrechnung

## Definition und Entscheidungskriterium

Die Gewinnvergleichsrechnung dient dazu eine Entscheidung treffen zu können, ob in ein Objekt investiert werden soll. Dazu wird für ein oder mehrere Investitionsobjekte der durchschnittlich zu erwartende Gewinn (d.h. Erlöse minus Kosten) berechnet. Ist dieser positiv, sollte in das Objekt investiert werden.

Entscheidungsmöglichkeiten: Einzelinvestition vs. Auswahlproblem

1. Investition oder Nicht-Investition („Wenn die durchschnittlichen Gewinne einer Investitionsalternative positiv sind ⇒ Investition tätigen")
2. Investition in A und B („Wenn die durchschnittlichen Gewinne einer Investition A höher sind als die einer Alternativinvestition B ⇒ Investiere in A.")

**Gewinn = Erlöse − Kosten**

## Ergebnisplanung

Bei der Ergebnisplanung werden die erwarteten Erlöse und Kosten aus einer Investition für den Zeitraum der Durchführung geschätzt. Als Ergebnis bleibt der erwartete Gewinn.

| | Jahr 1 | Jahr 2 | … | Jahr t |
|---|---|---|---|---|
| **Erlöse** | | | | |
| aus Umsätzen | | | | |
| aus sonstigen Positionen | | | | |
| **Kosten** | | | | |
| Materialkosten | | | | |
| Personalkosten | | | | |
| Kalkulatorische Abschreibungen | | | | |
| Kalkulatorische Zinskosten | | | | |
| **Gewinn (Betriebsergebnis)** | | | | |

## Begriffe der Kostenrechnung

**Kosten** sind der „bewertete, betriebszweckbezogene Güterverbrauch" eines Unternehmens.

- **Betriebszweckbezogen** bedeutet, dass der Güterverbrauch für die relevante Periode und im normalen Geschäftsbetrieb angefallen ist.
- **Güterverbrauch** bedeutet, dass die Kosten erst entstehen, wenn die Güter (z.B. Material) wirklich verbraucht sind.
- Beispiel: Verbrauch von Rohmaterial in der Produktion, Bezahlung von Mitarbeitern.

**Erlöse** sind Erträge aus Verkauf von Produkten und der Erbringung von Dienstleistungen.

### Operative und kalkulatorische Kosten

**Operativ** sind Kosten und Erlöse, wenn sie im normalen Geschäftsbetrieb angefallen sind (auch: **pagatorische Kosten**). Zu den operativen Kosten eines Restaurants gehören:

- Löhne und Gehälter der Mitarbeiter,
- Wert für den Verbrauch von Materialien für die Erstellung von Gerichten und Getränken,
- Miete für die Räume, in denen die Gäste und Küche untergebracht sind, und
- Abschreibungen auf die für die Produktion benötigten Geräte über ihre gesamte Nutzungsdauer.

**Kalkulatorische Kosten** beruhen nicht auf tatsächlichen Zahlungsvorgängen, sondern auf dem sog. **Opportunitätskostenprinzip**. Sie stellen Erlöse dar, die man nicht erzielt hat (die entgangen sind), weil man eine bestimmte Handlung nicht durchgeführt hat (z.B. kalkulatorische Eigenkapitalkosten, kalkulatorische Miete).

## Kalkulatorische Abschreibungen

Vermögensgegenstände verlieren über ihre Nutzungsdauer an Wert. Dieser Wertverlust wird über Abschreibungen abgebildet.

Hierbei kann es Unterschiede zwischen der **bilanziellen Abschreibung (FIBU)** und der **kalkulatorischen Abschreibung (tatsächlicher Wertverzehr)** geben, z.B. wenn die Nutzungsdauer oder der Restwert unterschiedlich geschätzt werden. **Für die Gewinnvergleichsrechnung sind die kalkulatorischen Abschreibungen relevant.**

Beispiel: Ein Ofen wird zu Jahresbeginn für 5.000,- € angeschafft.

- Bilanziell: lineare Abschreibung in der GuV über 4 Jahre (durch AfA-Tabellen vorgeschrieben) → **1.250 € p.a.**
- Kalkulatorisch: in der Kostenrechnung wird die Nutzungsdauer auf 10 Jahre geschätzt → **500 € p.a.**

**Jährlicher Wertverlust (Abschreibung) = (Anfangsinvestition − Restwert) / Nutzungsdauer**

### Exkurs: Abschreibung in der Praxis

Bei den linearen planmäßigen Abschreibungen wird für technische Anlagen sowie für andere Anlagen, Betriebs- und Geschäftsausstattung von einer Nutzungsdauer von zwei bis dreiundzwanzig Jahren ausgegangen. (Jahresabschluss Mercedes-Benz AG 2025, S. 7)

## Kalkulatorische Zinskosten

Die kalkulatorischen Zinskosten setzen sich zusammen aus den (pagatorischen) Kosten für Fremdkapital (Fremdkapitalzinsen) und den kalkulatorischen Kosten für das Eigenkapital (entgangene Erträge für das Eigenkapital).

Sie stellen die entgangenen Zinserträge (Opportunitätskosten) für die Eigen- und Fremdkapitalgeber dar, die ihnen entgangen sind, da sie das Geld in das Unternehmen investiert haben.

**Kalkulatorische Zinskosten = durchschnittlich eingesetztes Kapital × Kapitalkostensatz**

**Durchschnittlich investiertes Kapital = (Anfangsinvestition + Restwert) / 2**

## Formel der Gewinnvergleichsrechnung

G = (x · p) − ( (x · k_var) + K_fix + (I₀ − R_n)/n + (I₀ + R_n)/2 · i )

mit:

- G = Gewinn (pro Jahr)
- x = Produktionsmenge (pro Jahr)
- p = Absatzpreis (pro Stück)
- k_var = laufende variable Kosten (pro Stück)
- K_fix = laufende Fixkosten (pro Jahr)
- I₀ = Investitions- bzw. Anschaffungsausgabe
- R_n = Restwert bzw. Liquidationserlös
- n = Nutzungsdauer
- i = kalkulatorischer Zinssatz

## Beispiel

Die beiden alternativen Produktionsanlagen stellen unterschiedliche Produkte her. Vergleichen Sie die beiden Anlagen anhand ihres durchschnittlichen Gewinns pro Jahr! (Kalkulationszinssatz = 10%)

| | Anlage I | Anlage II |
|---|---|---|
| 1. Anschaffungsausgabe [€] | 100.000,- | 86.000,- |
| 2. Restwert am Ende der Nutzungsdauer [€] | 20.000,- | 10.000,- |
| 3. Nutzungsdauer [Jahre] | 8 | 8 |
| 4. Geplante Produktions- und Absatzmenge [Stück/Jahr] | 16.000 | 12.000 |
| 5. Laufende fixe Kosten [€/Jahr] | 2.000,- | 900,- |
| 6. Variable Lohn- und Materialkosten [€/Stück] | 0,50 | 0,55 |
| 7. Energie- und sonstige variable Kosten [€/Stück] | 0,25 | 0,35 |
| 8. Verkaufspreis [€/Stück] | 2,25 | 2,60 |

Lösung:

| | Anlage I | Anlage II |
|---|---|---|
| Umsatzerlöse | 16.000 · 2,25 = 36.000 € | 12.000 · 2,60 = 31.200 € |
| Laufende variable Kosten | 16.000 · 0,75 = 12.000 € | 12.000 · 0,90 = 10.800 € |
| Laufende fixe Kosten | 2.000 € | 900 € |
| Kalkulator. Abschreibungen | (100'−20') : 8 = 10.000 € | (86'−10') : 8 = 9.500 € |
| Kalkulator. Zinsen | (100'+20') : 2 · 0,1 = 6.000 € | (86'+10') : 2 · 0,1 = 4.800 € |
| Gesamtkosten | 30.000 € | 26.000 € |
| **Gewinn** | **36.000 − 30.000 = 6.000 €** | **31.200 − 26.000 = 5.200 €** |

## Nachteile der Gewinnvergleichsrechnung

**Kurzfristigkeit des Gewinnvergleiches**

- Üblicherweise erfolgt die Berechnung für ein Jahr und damit bleiben Entwicklungen im Zeitverlauf unberücksichtigt. Besonders problematisch ist, wenn sich der Gewinnvergleich auf das erste Jahr der Nutzung bezieht.
- Bei Alternativen unterschiedlicher Nutzungsdauer keine Aussage, welcher Gewinn für den Differenzzeitraum.
- Unterschiedlich hohe Investitionsausgaben; damit wird unterstellt, dass der Differenzbetrag keinen über den kalk. Zinssatz hinausgehenden Gewinn erwirtschaftet.

**Zurechenbarkeit der Erlöse**

Die Zurechenbarkeit zu einem Investitionsobjekt kann problematisch sein, wenn das Produkt auf mehreren Maschinen gefertigt wird.

**Nichtberücksichtigung des Kapitaleinsatzes**

Die Einbeziehung des Kapitaleinsatzes zeigt erst, inwieweit eine Investition wirklich rentabel ist.
