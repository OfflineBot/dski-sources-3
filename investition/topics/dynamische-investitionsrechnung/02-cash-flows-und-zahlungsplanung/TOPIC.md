# Cash Flows und Zahlungsplanung

## Ein- und Auszahlungen

**Einzahlungen (Cash Inflow):** Als „Einzahlung" bezeichnet man einen Zufluss von liquiden Mitteln in das Unternehmen. Eine Einzahlung liegt immer vor, wenn das Konto „Kasse/Bank" erhöht wird.

**Auszahlungen (Cash Outflow):** Als „Auszahlung" bezeichnet man den Abfluss von liquiden Mitteln aus dem Unternehmen. Darin eingeschlossen sind physische Geldmittel sowie Bankguthaben. Eine Auszahlung liegt immer vor, wenn das Konto „Kasse/Bank" reduziert wird.

## Die drei Arten von Cash Flows

| Art | Bildet ab | Beispiel |
|---|---|---|
| Cashflow aus laufender Geschäftstätigkeit | operative Zahlungsflüsse | Auszahlungen an Lieferanten, Einzahlungen aus Verkäufen |
| Cashflow aus Investitionstätigkeit | Zahlungsflüsse aus Investitionen und Desinvestitionen in langfristiges Anlagevermögen | Investition in Maschinen |
| Cashflow aus Finanzierungstätigkeit | Zahlungsflüsse aus Finanzierungen von Eigen- und Fremdkapital | Aufnahme von Darlehen, Rückzahlung von Darlehen |

**Free Cash Flow = Operativer Cash Flow + Investitions-Cash Flow**

Geld für Dividenden der Aktionäre bzw. Gesellschafter oder für eine fällige Rückführung der Fremdfinanzierung.

## Bestimmung der operativen Cashflows

Der operative Cash Flow ist — im Gegensatz zu den kalkulatorischen Größen der Kosten- und Leistungsrechnung — **zahlungsorientiert** und berücksichtigt nur Transaktionen, die zu Ab- oder Zuflüssen von liquiden Mitteln führen.

Die Ermittlung des operativen Cashflows kann **direkt** aus den gesamten Geschäftsvorfällen des Unternehmens oder **indirekt** aus der Gewinn- und Verlustrechnung erfolgen.

### Schema

| Position | Gesamt | Davon zahlungswirksam | Davon nicht zahlungswirksam |
|---|---|---|---|
| Umsatzerlöse | | | |
| - Materialkosten | | | |
| - Personalkosten | | | |
| - kalk. Zinskosten | | | |
| - Abschreibung | | | |
| Gewinn | | | |
| Operativer Cash Flow | | | |

### Beispiel

Ein Unternehmen hat in einem Jahr folgende Geschäftsvorfälle:

- An Kunden werden Waren für 100 € verkauft. 90% der Kunden zahlen in bar, 10% auf Rechnung.
- Material wird für 30 € beschafft und verbraucht. 5 € der Lieferantenrechnung werden nicht direkt beglichen.
- An das Personal werden 40 € als Gehalt überwiesen.
- Abschreibungen fallen in Höhe von 10 € an.
- Kalkulatorische Eigenkapitalkosten fallen in Höhe von 5 € an.

Ermitteln Sie Gewinn und operativen Cash Flow. Warum kommt es zu Abweichungen?

Lösung:

| Position | Gesamt | Davon zahlungswirksam | Davon nicht zahlungswirksam |
|---|---|---|---|
| Umsatzerlöse | 100 | 90 | 10 |
| - Materialkosten | 30 | 25 | 5 |
| - Personalkosten | 40 | 40 | 0 |
| - kalk. Zinskosten | 5 | 0 | 5 |
| - Abschreibung | 10 | 0 | |
| **Gewinn** | **15** | | |
| **Operativer Cash Flow** | | **25** | |

Der operative Cash Flow weicht in diesem Beispiel vom Gewinn ab, da

- Abschreibungen nicht zahlungswirksam sind,
- kalk. Zinskosten und kalk. Eigenkapitalkosten nicht zahlungswirksam sind,
- nicht alle Umsatzerlöse zahlungswirksam sind.

## Zahlungsplanung

Bei der Zahlungsplanung werden die erwarteten Cash-Inflows und Outflows aus einer Investition für den Zeitraum der Durchführung geschätzt. Als Ergebnis bleibt der erwartete Free Cash Flow.

| | Jahr 1 | Jahr 2 | … | Jahr t |
|---|---|---|---|---|
| Investitions-Cash Flow | | | | |
| + Operativer Cash Flow | | | | |
| = Free Cash Flow | | | | |
