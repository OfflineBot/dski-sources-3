# Klausurrelevant: die roten K

Alles in `topics/` ist wichtig. Was der Prof mit einem roten **K** markiert hat, ist besonders klausurrelevant: **Das muss man können.**

Diese Datei enthält keinen Stoff, sie verweist nur auf die Stellen.

- In den Topics steht an der markierten Stelle `[K]` (K von diesem Jahr) oder `[K Vorjahr]` (K nur im Vorjahr).
- aktuell = `origin/mitschriebt_3_von_5_aktuell.pdf` (Handschrift bisher nur auf Folie 1–59)
- Vorjahr = `origin/mitschrieb_letzte_jahr.pdf` (Handschrift auf allen Kapiteln außer Plankostenrechnung, die es dort nicht gibt)

Reihenfolge zum Lernen: Grundlagen → Kostenartenrechnung → Kostenstellenrechnung → Kostenträgerrechnung → Teilkostenrechnung → Plankostenrechnung.
