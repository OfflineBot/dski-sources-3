# Kosten und Gewinn

An einer Fachhochschule wird von einer Gruppe von Studierenden eine monatlich erscheinende Zeitung erstellt und vertrieben. Es werden 400 Stück zu einem Preis von 5 € verkauft.

Kosten fallen zum einen für die monatliche Miete des genutzten Kopiergeräts in Höhe von 500 € und zum anderen für Papier und andere Materialien in Höhe von 2,50 € pro Exemplar an.

a) Ermitteln Sie die Kostenfunktion.

b) Wie hoch ist der Gewinn der Studierenden?

c) Ab welcher Menge wird ein Gewinn erzielt?
