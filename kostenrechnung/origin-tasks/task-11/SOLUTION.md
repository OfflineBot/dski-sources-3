# Lösungen Einfache Aufgaben zur Abweichungsanalyse

Fett = auf der Folie grau hinterlegt.

## a)

xplan = **320**

| Gesamtkosten | | Stückkosten | |
|---|---|---|---|
| Kv | 4.160 | kv | 13 |
| Kf | **4.800** | kf | 15 |
| K | **8.960** | k | 28 |

- K_Soll(x_IST=300) = 4.800 + 13 * 300 = 8.700
- K_Verr(x_Ist=300) = 28 * 300 = 8.400

| | | |
|---|---|---|
| Beschäftigungsabweichung | = K_Verr(x_Ist=300) - K_Soll(x_IST=300) | = 8.400 – 8.700 = -300 |
| + Verbrauchsabweichung | = K_Soll(x_Ist=300) - K_IST | = 8.700 – 8.480 = +220 |
| = Gesamtabweichung | = K_IST - K_Verr(x_Ist=300) | = 8.400 – 8.480 = -80 |

## b)

xplan = **200**

| Gesamtkosten | | Stückkosten | |
|---|---|---|---|
| Kv | 3.000 | kv | **15** |
| Kf | **4.800** | kf | 24 |
| K | 7.800 | k | 39 |

- K_Soll(x_IST=240) = 4.800 + 15 * 240 = 8.400
- K_Verr(x_Ist=240) = 39 * 240 = 9.360

| | | |
|---|---|---|
| Beschäftigungsabweichung | = K_Verr(x_IST=240) – K_Soll(x_Ist=240) | = 9.360 - 8.400 = 960 |
| + Verbrauchsabweichung | = K_Soll – K_Ist(x_Ist=240) | = 8.400 - 8.280 = 120 |
| = Gesamtabweichung | = K_Verr(x_Ist=240) - K_IST | = 9.360 - 8.280 = 1.080 |

## Hinweis zur Vorlage

In a) nennt die Aufgabe Istkosten von 8.400 € im Monat, die Lösung rechnet mit K_IST = 8.480.
Die Gesamtabweichung steht dort als K_IST - K_Verr, die Zahlen als 8.400 – 8.480. Das ist so übernommen.
