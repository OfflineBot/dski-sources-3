Die Folien enthalten keine gedruckte Lösung. Alles hier ist die Handschrift des Profs aus dem Vorjahr.

## A4 9.

Die Handschrift kürzt Millionen mit einem Hochstrich ab: 8' = 8.000.000 € (Variable Kosten), 1,5' = 1.500.000 € (Fixe Kosten), 2,5' = 2.500.000 € (Gewinn).

| | | |
|---|---|---|
| p * x | = U | 12' |
| - k_v * x | => K_v | 8' |
| db * x | DB | = 4' |

- Links an der Aufgabe: Gewinn und Fixe Kosten mit einer Klammer zusammengefasst: DB = 4'
- Skizze eines Eimers: oben 4' (eingekreist), im Eimer bis zur Marke K_F: 1,5', im Überlauf: G = 2,5'
- U / DB = 12 / 4 = 3 / 1
- db / p = 33,3 %
- U* = K_F / (db / p) = 1,5' * 3 = 4,5'
